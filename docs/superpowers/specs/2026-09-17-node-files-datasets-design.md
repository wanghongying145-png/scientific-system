# 节点文件、数据集与样本关联

统一数据集台账承载项目 ID、产出节点 ID、文件列表和样本 ID 列表。一个数据集属于一个明确节点；一个节点可以有多个数据集。每个数据集可包含多个文件、多个样本；一个样本可关联多个数据集。多对多关系只存储于数据集样本 ID 列表，样本侧反查，避免双份关系不同步。

节点六页右侧抽屉保留。原始实验数据页按数据集展示文件和来源样本，并复用新增/编辑表单。数据集管理提供类别、项目、节点、样本及关键词筛选，以及按项目分组的“节点对应关系”视图。样本详情可查看和维护关联数据集。

项目节点样本展示直接关联样本与数据集来源样本的去重并集。来源数据集关联实时推导，不复制样本、不额外写入直接关联；来源关系的解除应从数据集或样本的数据集关联入口完成。

既有 48 条数据集保留稳定编号、质量信息和项目节点关系。原始节点的 8 条文件登记迁入明确对应的立项数据集，仅保留历史登记，不伪造可下载文件内容。未能确定节点的历史记录展示待关联节点，编辑时必须明确真实节点。

实际选择的文件内容保存于浏览器 IndexedDB，元数据与关系保存于 localStorage；支持刷新和同源多标签页同步。文本文件可预览，已有内容可下载；历史登记未附原文件时禁用下载。新增文件失败不产生空成功记录。修改文件后重置为待质检，不模拟质检结果。

数据集删除解除其节点和样本对应关系并清理本地文件，不删除样本。含数据集的项目/节点及被数据集引用的样本受删除保护。项目、节点、样本更名均通过稳定 ID 解析新名称；修改数据集产出节点会即时更新两个节点的清单。其他页面更新过的数据集需重新打开编辑，避免覆盖较新数据。

验收覆盖多样本数据集、样本多数据集、双方编辑解绑、节点归属修改、文件选择/追加/移除、刷新下载内容校验、历史迁移、删除联动、改名排序、同源标签页同步和原右侧抽屉保留；类型检查及生产构建。
