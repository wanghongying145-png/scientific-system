# 科研样本统一台账与关联

## 用户要求
样本先进入统一台账，再关联项目和具体实验节点。项目内新增必须写入同一台账。样本页面不展示患者、疾病、性别、年龄、住院、用药、提取、建库、上机或临床检测信息。

## 数据与操作
台账记录采用稳定样本 ID 与唯一编号，字段为名称、类型、批次、数量/单位、存放位置、保管人、入库日期、状态、备注和创建/更新时间。
状态包括待入库、可用、使用中、已耗尽、已归档。类型可选择常见科研材料，也可直接填写。
每个样本保存多条项目 ID + 节点 ID 关联，节点必须属于所选项目；同一组合不可重复。允许未关联登记，允许复用于多个项目或节点，不复制台账记录。
从项目或节点新增，默认填入当前项目/节点，并由同一个保存函数写入台账。从项目选择已有样本，只追加关联。解除某个节点关联不影响其他关联，不删除样本。
列表、详情、项目样本页和节点抽屉均读取同一台账；工作台样本数量按样本 ID 去重统计。项目/节点名称通过 ID 解析，改名和排序不影响关联。
存在样本关联时禁止删除对应项目或节点；关联中的样本不可直接删除，可归档或先解除关联。未关联样本删除需确认。

## 兼容与边界
保留之前两条样本的编号和科研材料类型，以待核对科研资料展示，不沿用患者或临床数据。旧项目单独保存的样本勾选记录按 ID 导入台账，保留项目关系并标注“待补充节点”，不虚构具体节点。确认节点后转换为正式关联。
当前仍为浏览器本地原型，统一存储键为 research_samples_v1。支持同源浏览器标签页同步与刷新保留，尚无服务端、多设备或库存出入库流水。
实验节点已有研究方案和数据集业务保持原用途，本阶段只移除样本管理中的临床检测字段。

## 验证
独立浏览器验收覆盖新增、编辑、取消、唯一编号、数量及关联校验、从项目/节点新增、选择已有样本、多项目复用、单节点解绑、名称联动、刷新与同源多标签页同步、历史关联迁移、删除保护及 CSV 导出。执行类型检查与生产构建。
