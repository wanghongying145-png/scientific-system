# 项目与实验节点统一（第一阶段）

项目管理的新建、编辑共用一套表单：基本资料、PI 与成员、研究目标及验收指标、项目计划和周期、研究类型、实验节点。

研究类型包括合成生物学与酶工程、病原与基因组测序、单细胞与多组学研究、药物发现与验证、自定义研究。首次选择生成模板节点；新建时未调整的模板可随类型切换替换；已经调整或保存的节点保留，通过“补充模板节点”追加缺少的节点。

项目与节点各有稳定编号。名称和排序不作为关联依据。节点可指定本项目 PI 或成员作为负责人，可配置起止日期和任务说明。有执行记录或关联数据集的节点不允许删除。

必填校验覆盖编号、名称、PI、成员、目标、计划、周期、研究类型和至少一个节点。编号与同项目节点名称不可重复；节点周期必须位于项目周期内；移除团队成员后需重新指定其负责的节点。

项目管理、工作台项目卡片、项目详情及数据集项目/节点选择使用公共项目数据源。历史数据集无法与对应研究流程匹配的节点展示“未关联节点”，不自动迁入不相关节点。节点更名与排序保留关联编号。

当前为前端原型，项目、PI 和数据集登记信息保存于当前浏览器 localStorage。尚无服务端多人同步、真实文件上传和质检实现；样本业务及工作台其他统计联动留待后续阶段。

验收通过独立浏览器执行创建、编辑、取消、刷新、校验失败、模板切换、节点改名/排序、执行记录保护、工作台跳转与数据集选择联动；另外执行类型检查与生产构建。
